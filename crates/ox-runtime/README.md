# ox-runtime

Wasmtime-based agent runtime for ox.

Part of [Ox](https://github.com/freeoxen/ox), an agentic coding system built on
StructFS. Requires Rust 1.96 or newer.

See the [project documentation](https://github.com/freeoxen/ox#readme) for
installation and usage, and the [release guide](https://github.com/freeoxen/ox/blob/main/docs/releasing.md)
for the coordinated package release process.
